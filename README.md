# Intelligent Insurance Claims Automation

Portfolio project for Data Science / Automation Manager interviews.

## Start here
1. Open `04_LocalPortal/start_server.bat`.
2. Browse to `http://127.0.0.1:8000/`.
3. Open UiPath Studio.
4. Build the browser smoke test first.
5. Then build CSV -> Queue.
6. Then convert the processor to REFramework.
7. Then add exceptions, retries, HITL, Orchestrator and reporting.

## Public reference
UiPath has an insurance claims end-to-end automation demo and current insurance automation guidance. This project uses those concepts while keeping the executable demo independent of a third-party site's UI changes.

All claim data in this package is synthetic.
